# 🏭 בקרת איכות פודים - QC Pods App

אפליקציית ניהול בקרת איכות לייצור פודים במפעל, בנויה עם HTML/CSS/JavaScript ו-Supabase.

---

## 🚀 הגדרת הסביבה

### 1. הקמת Supabase

1. צור חשבון ב-[supabase.com](https://supabase.com)
2. צור פרויקט חדש
3. לחץ על **SQL Editor** → **New Query**
4. הדבק את תוכן הקובץ `supabase/schema.sql` ולחץ **Run**
5. לך ל-**Settings → API** ועתק:
   - `Project URL`
   - `anon public` key

### 2. הגדרת האפליקציה

פתח את `js/config.js` ועדכן:
```javascript
const SUPABASE_URL = 'https://YOUR_PROJECT_ID.supabase.co';
const SUPABASE_ANON_KEY = 'YOUR_ANON_KEY';
```

### 3. הפעלה

פתח את `index.html` בדפדפן, או השתמש ב-serve:
```bash
npx serve . -p 3000
```

## 🔍 שלבי בקרה (6 קבוצות)

1. **יציקת רצפת בטון** - מידות, שיפוע צינור, בדיקת דלוחין ועוד
2. **קונסטרוקציית קירות ותקרה** - אלכסונים, מידות, פתח דלת
3. **אינסטלציה וחשמל** - בדיקת לחץ, אסלה, תקרה, חשמל
4. **איטום** - קולרים, סרטים, שכבת איטום
5. **קרמיקה ורובה** - מישוריות, רווחים, רובה, מפגשים
6. **אביזרי קצה** - כל האביזרים הסופיים

## 📄 פלטים

- **PDF** - דוח בקרה מלא לכל פוד (ייצוא ישיר)
- **Excel** - טבלאות התקדמות לפי טיפוס וכיוון
- **ברקוד** - CODE128 מוכן להדפסה לכל פוד

## ☁️ חיבור OneDrive

1. פתח OneDrive וצור תיקייה לפרויקט
2. לחץ ימני → שתף → "כל מי שיש לו את הקישור"
3. העתק את הקישור
4. באפליקציה: פרויקט → פרטים נוספים → הדבק בשדה OneDrive
5. בייצוא PDF, יפתח OneDrive אוטומטית

## 🛠️ Stack טכנולוגי

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES2020)
- **Database**: Supabase (PostgreSQL)
- **Libraries** (CDN):
  - `@supabase/supabase-js` - חיבור לבסיס נתונים
  - `JsBarcode` - יצירת ברקודים
  - `jsPDF` - יצירת קבצי PDF
  - `SheetJS (xlsx)` - יצירת קבצי Excel
  - `signature_pad` - שדה חתימה דיגיטלי
